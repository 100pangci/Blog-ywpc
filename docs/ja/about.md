# 私について

**ywpc** と申します。「百分百原味胖次（100% 元味パンツ）」から「**原味胖次**」を取った略称です。

普段は Linux、Android、コンテナ、ネットワーク、オープンソースプロジェクト、AI エージェント、そしてギャルゲー漢化（中国語翻訳）関連ツールなどを主にいじっています。

## Linux / NAS

デスクトップのメイン環境は **Fedora KDE**、NAS は **Fedora Server** を使用しています。

NAS は Windows Server から移行したもので、現在は主に systemd + Podman でサービスを管理し、自作の [Fedora-NAS-Config](https://github.com/100pangci/fedora-nas-config) をメンテナンスしています。
